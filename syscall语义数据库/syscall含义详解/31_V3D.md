# V3D 分组 syscall 含义详解

## 1. 分组范围与结论概览

依据 [`README.md`](fvp_analysis/result/syscall语义数据库/README.md:111)、[`syscall_spec.json`](fvp_analysis/result/syscall语义数据库/syscall_spec.json:7722-7978) 与 rfvp 参考实现，`V3D` 分组当前包含 5 个 syscall：

1. `V3DMotion`
2. `V3DMotionPause`
3. `V3DMotionStop`
4. `V3DMotionTest`
5. `V3DSet`

其实现位于 [`motion.rs`](fvp_analysis/reference/rfvp-0.3.0/crates/rfvp/src/subsystem/components/syscalls/motion.rs:683-813)，底层容器位于 [`v3d.rs`](fvp_analysis/reference/rfvp-0.3.0/crates/rfvp/src/subsystem/resources/motion_manager/v3d.rs:1-410)。

`V3D` 组的整体语义可以概括为：

> **围绕全局三维坐标/相机参数的直接设置、时间型三维运动、暂停、停止和状态查询的一组接口。**

它与 `Prim` 组中的 [`PrimSetZ`](fvp_analysis/result/syscall语义数据库/syscall含义详解/21_Prim.md:663) 不同：

- `V3DSet` 设置的是全局 V3D 当前坐标；
- `V3DMotion` 推进的是全局 V3D 坐标到目标值的运动；
- `PrimSetZ` 设置的是单个 prim 的 Z 属性，并可开启对应的投影属性位。

## 2. V3D 运行模型

### 2.1 单一全局 V3D motion 容器

[`V3dMotionContainer`](fvp_analysis/reference/rfvp-0.3.0/crates/rfvp/src/subsystem/resources/motion_manager/v3d.rs:151-167) 内部只保存一条 `V3dMotion`：

- 当前 X；
- 当前 Y；
- 当前 Z；
- 源坐标；
- 目标坐标；
- 持续时间；
- elapsed；
- motion 类型；
- reverse 标志；
- paused 标志。

因此，V3D 不是以 prim ID 为键的多对象动画容器，而是一个全局三维运动状态。

### 2.2 三维坐标的作用

V3D 坐标会参与具有相应投影属性的 prim 的渲染模型矩阵。当前 [`gpu_prim.rs`](fvp_analysis/reference/rfvp-0.3.0/crates/rfvp/src/rendering/gpu_prim.rs:288-316) 在 `attr & 0x04` 时使用：

- prim Z 与 V3D Z 的差值作为 depth；
- V3D X/Y 产生相机偏移；
- prim 缩放和 V3D depth 共同影响最终模型矩阵。

因此 V3D syscall 并不直接修改单个图元的 x/y/z 字段，而是作为全局投影参数参与多个 prim 的绘制。

### 2.3 V3D 更新链

V3D motion 由 [`MotionManager::update_v3d_motions()`](fvp_analysis/reference/rfvp-0.3.0/crates/rfvp/src/subsystem/resources/motion_manager/mod.rs:274-280) 在帧更新时推进：

1. 更新 V3D motion elapsed；
2. 按 easing 类型计算当前 X/Y/Z；
3. 写入 V3D 当前坐标；
4. 将启用 V3D 投影的 prim 标记 dirty；
5. 渲染器在后续绘制中重新计算模型矩阵。

## 3. `V3DSet`

### 3.1 参数与返回

- **参数个数**：3：[`syscall_spec.json`](fvp_analysis/result/syscall语义数据库/syscall_spec.json:7894)
- **签名**：`V3DSet(x, y, z)`
- **返回值**：`Nil`
- **控制流**：无 yield / wait / sleep / halt

### 3.2 入参语义

- `x`
  - 类型：`Int | Nil`；
  - `Int`：设置当前 V3D X；
  - 非整数：保持当前 X。
- `y`
  - 类型：`Int | Nil`；
  - `Int`：设置当前 V3D Y；
  - 非整数：保持当前 Y。
- `z`
  - 类型：`Int | Nil`；
  - `Int`：设置当前 V3D Z；
  - 非整数：保持当前 Z。

### 3.3 具体作用

[`v3d_set()`](fvp_analysis/reference/rfvp-0.3.0/crates/rfvp/src/subsystem/components/syscalls/motion.rs:795-813) 读取三个参数：

- 参数为整数时使用传入值；
- 参数不是整数时调用当前 V3D 值作为默认值；
- 最后调用 [`MotionManager::set_v3d()`](fvp_analysis/reference/rfvp-0.3.0/crates/rfvp/src/subsystem/resources/motion_manager/mod.rs:471-473)。

它不创建 motion，不改变 duration/easing，也不设置 paused。

### 3.4 结论

> `V3DSet` 是 **直接设置全局三维当前坐标的接口**，`Nil` 或非整数参数表示保留对应坐标。

---

## 4. `V3DMotion`

### 4.1 参数与返回

- **参数个数**：6：[`syscall_spec.json`](fvp_analysis/result/syscall语义数据库/syscall_spec.json:7727)
- **签名**：`V3DMotion(dst_x, dst_y, dst_z, duration, typ, reverse)`
- **返回值**：`Nil`
- **控制流**：不直接 yield；运动由帧循环异步推进。

### 4.2 入参语义

- `dst_x`
  - 类型：`Int | Nil`；
  - `Int`：目标 V3D X；
  - `Nil`：保持当前 X 作为目标。
- `dst_y`
  - 类型：`Int | Nil`；
  - `Int`：目标 V3D Y；
  - `Nil`：保持当前 Y 作为目标。
- `dst_z`
  - 类型：`Int | Nil`；
  - `Int`：目标 V3D Z；
  - `Nil`：保持当前 Z 作为目标。
- `duration`
  - 类型：`Int`；
  - 有效范围：`1..=300000`；
  - 单位：毫秒。
- `typ`
  - 类型：`Int | Nil`；
  - `Nil` 默认按 `Linear`；
  - 当前支持 `Linear`、`Accelerate`、`Decelerate`、`Rebound`、`Bounce`；
  - `0` 或非法值会回退到 `Linear`。
- `reverse`
  - 类型：任意 `Variant`；
  - `Nil`：关闭 reverse；
  - 非 `Nil`：开启 reverse 存在性标志。

### 4.3 具体作用

[`v3d_motion()`](fvp_analysis/reference/rfvp-0.3.0/crates/rfvp/src/subsystem/components/syscalls/motion.rs:683-754) 会：

1. 读取当前 V3D 坐标作为 `Nil` 目标参数的默认值；
2. 校验 duration；
3. 将 `typ` 映射为 [`V3dMotionType`](fvp_analysis/reference/rfvp-0.3.0/crates/rfvp/src/subsystem/resources/motion_manager/v3d.rs:4-28)；
4. 把目标坐标、duration、motion type、reverse 写入 V3D motion 容器；
5. 由帧循环逐步推进全局 V3D 坐标。

### 4.4 运动类型

当前枚举定义为：

| 数值 | 类型 | 含义 |
|---:|---|---|
| 0 | `None` | 无运动/内部保留值 |
| 1 | `Linear` | 线性插值 |
| 2 | `Accelerate` | 加速插值 |
| 3 | `Decelerate` | 减速插值 |
| 4 | `Rebound` | 回弹效果 |
| 5 | `Bounce` | 弹跳效果 |

`V3DMotion` 对 `None` 和非法值回退到 `Linear`，见 [`motion.rs`](fvp_analysis/reference/rfvp-0.3.0/crates/rfvp/src/subsystem/components/syscalls/motion.rs:733-738)。

### 4.5 具体运动行为

[`V3dMotionContainer::exec_v3d_update()`](fvp_analysis/reference/rfvp-0.3.0/crates/rfvp/src/subsystem/resources/motion_manager/v3d.rs:240-396) 会根据不同类型计算三个坐标：

- `Linear`：按 elapsed/duration 线性插值；
- `Accelerate`：使用 elapsed 的平方比例；
- `Decelerate`：使用剩余时间的平方比例；
- `Rebound`：分段计算先越界/回弹再趋向目标；
- `Bounce`：分段计算弹跳式坐标变化。

运动完成后：

- 当前坐标达到目标；
- motion type 变为 `None`；
- `V3DMotionTest` 返回未运行状态。

### 4.6 结论

> `V3DMotion` 是 **把全局三维坐标在指定时长内按 easing 类型推进到目标值的接口**。

## 5. `V3DMotionPause`

### 5.1 参数与返回

- **参数个数**：1：[`syscall_spec.json`](fvp_analysis/result/syscall语义数据库/syscall_spec.json:7794)
- **签名**：`V3DMotionPause(pause)`
- **返回值**：`Int | Nil`
- **控制流**：无 VM 调度副作用。

### 5.2 入参语义

- `pause`
  - 类型：`Int | Nil`；
  - `Int(0)`：恢复 V3D motion；
  - 非零 `Int`：暂停 V3D motion；
  - `Nil`：查询当前暂停状态；
  - 其他类型：返回 `Nil`，不修改状态。

### 5.3 返回值

当 `pause == Nil` 时：

- `Int(1)`：当前 V3D motion 已暂停；
- `Int(0)`：当前 V3D motion 未暂停。

设置分支返回 `Nil`。

### 5.4 具体作用

[`v3d_motion_pause()`](fvp_analysis/reference/rfvp-0.3.0/crates/rfvp/src/subsystem/components/syscalls/motion.rs:756-777) 调用 [`set_v3d_motion_paused()`](fvp_analysis/reference/rfvp-0.3.0/crates/rfvp/src/subsystem/resources/motion_manager/mod.rs:475-480)。

在更新函数中，如果 motion 已暂停，则不会推进 elapsed 或更新当前坐标：[`v3d.rs`](fvp_analysis/reference/rfvp-0.3.0/crates/rfvp/src/subsystem/resources/motion_manager/v3d.rs:240-247)。

### 5.5 与 `MotionPause` 的区别

- `MotionPause(id, pause)`：暂停某个 prim 的多种普通 motion；
- `V3DMotionPause(pause)`：暂停唯一的全局 V3D motion；
- V3D pause 不接受 prim ID。

### 5.6 结论

> `V3DMotionPause` 是 **全局 V3D motion 的暂停/恢复及状态查询接口**。

## 6. `V3DMotionStop`

### 6.1 参数与返回

- **参数个数**：0：[`syscall_spec.json`](fvp_analysis/result/syscall语义数据库/syscall_spec.json:7831)
- **签名**：`V3DMotionStop()`
- **返回值**：`Nil`
- **控制流**：无 VM 调度副作用。

### 6.2 具体作用

[`v3d_motion_stop()`](fvp_analysis/reference/rfvp-0.3.0/crates/rfvp/src/subsystem/components/syscalls/motion.rs:779-783) 调用 [`stop_v3d_motion()`](fvp_analysis/reference/rfvp-0.3.0/crates/rfvp/src/subsystem/resources/motion_manager/mod.rs:463-465)。

底层 [`V3dMotionContainer::stop_motion()`](fvp_analysis/reference/rfvp-0.3.0/crates/rfvp/src/subsystem/resources/motion_manager/v3d.rs:199-207) 会：

- 如果 motion 正在运行，将 motion type 设为 `None`；
- 把当前坐标设置为原 motion 的目标坐标；
- 结束当前 V3D motion。

因此它不是“冻结在当前位置”，而更接近：

> **立即结束 V3D motion，并把当前值收束到目标值。**

### 6.3 结论

> `V3DMotionStop` 是 **停止当前全局三维运动并完成到目标坐标的接口**。

## 7. `V3DMotionTest`

### 7.1 参数与返回

- **参数个数**：0：[`syscall_spec.json`](fvp_analysis/result/syscall语义数据库/syscall_spec.json:7861)
- **签名**：`V3DMotionTest()`
- **返回值**：`BoolLike`，即 `True/Nil`。

### 7.2 具体作用

[`v3d_motion_test()`](fvp_analysis/reference/rfvp-0.3.0/crates/rfvp/src/subsystem/components/syscalls/motion.rs:785-793) 查询 [`test_v3d_motion()`](fvp_analysis/reference/rfvp-0.3.0/crates/rfvp/src/subsystem/resources/motion_manager/mod.rs:467-469)：

- motion type 不为 `None`：返回 `True`；
- motion type 为 `None`：返回 `Nil`。

它不返回当前坐标、剩余时间或 motion type，只返回“是否有 V3D motion 正在运行”。

### 7.3 结论

> `V3DMotionTest` 是 **查询全局 V3D motion 是否仍在运行的轮询接口**。

## 8. V3D 与 Prim 渲染的边界

### 8.1 PrimSetZ 与 V3DSet 不同

[`PrimSetZ`](fvp_analysis/result/syscall语义数据库/syscall含义详解/21_Prim.md:663) 直接修改某个 prim 的 `z` 字段；`V3DSet` 修改的是全局 V3D 坐标。

当前渲染矩阵在 `attr & 0x04` 时同时使用：

- prim 的位置、缩放、pivot；
- prim Z；
- V3D X/Y/Z。

因此实际画面中的三维效果通常是两组状态共同作用的结果。

### 8.2 V3D 投影标志

V3D 更新函数会遍历 prim 树，并对启用 V3D 相关属性的 prim 标记 dirty：[`v3d.rs`](fvp_analysis/reference/rfvp-0.3.0/crates/rfvp/src/subsystem/resources/motion_manager/v3d.rs:240-268)。

如果 prim 没有启用对应属性位，修改 V3D 坐标可能不会让该 prim 使用三维投影路径。

### 8.3 V3D 不是 Prim 组动画

V3D 组接口不接受 prim ID：

- 不能用 `V3DMotionTest(prim_id)` 查询某个图元；
- 不能用 `V3DMotionStop(prim_id)` 停止某个图元；
- 它们只操作全局 V3D motion。

## 9. V3D 组整体语义

5 条 syscall 可以构成一个完整的全局三维动画流程：

```text
V3DSet(x, y, z)
V3DMotion(dst_x, dst_y, dst_z, duration, typ, reverse)

while V3DMotionTest() do
    V3DMotionPause(nil)   // 可选查询
    ThreadNext()
end

V3DMotionStop()           // 可选强制结束
```

暂停流程：

```text
V3DMotionPause(1)   // 暂停
V3DMotionPause(0)   // 恢复
V3DMotionPause(nil) // 查询 Int(0/1)
```

因此，V3D 分组的整体语义可以概括为：

> **FVP 的全局三维投影状态控制接口：直接设置当前三维坐标，或让三维坐标按时间和 easing 规则运动，并提供暂停、停止和运行状态查询。**

## 10. 高置信度结论

以下结论比较稳：

- `V3D` 分组当前共有 5 个 syscall。
- V3D 只维护一个全局三维 motion 容器，不以 prim ID 区分多个 motion。
- `V3DSet` 直接设置当前 X/Y/Z，非整数参数保持原值。
- `V3DMotion` 的目标坐标允许 `Nil`，表示保持当前对应坐标。
- `V3DMotion` 的 duration 有效范围为 `1..=300000` 毫秒。
- V3D motion 类型包括 Linear、Accelerate、Decelerate、Rebound、Bounce。
- 非 Nil 的 reverse 参数被视为开启 reverse 标志。
- `V3DMotionPause(nil)` 查询并返回 `Int(0/1)`。
- `V3DMotionStop()` 会结束 motion，并将当前坐标收束到目标坐标。
- `V3DMotionTest()` 返回 `True/Nil`，只表示是否仍有运行中的 V3D motion。
- V3D 坐标会参与带有 `attr & 0x04` 的 prim 投影模型计算。
- V3D 组不直接阻塞 VM，不包含 yield/wait/sleep 控制流副作用。

## 11. 仍需保守处理的点

1. `V3DSet` 中 X/Y/Z 的脚本业务名称可能是相机位置、观察点、投影偏移或其他三维场景参数；当前实现只能确认它们是全局三维坐标。
2. `V3DMotion` 的 reverse 行为在当前接口层明确按存在性判断，但具体反向运动时序仍需结合 motion 容器更新公式和实机表现验证。
3. `V3DMotionStop` 将当前值设置为目标值的行为已在容器实现中确认，但原版是否完全一致仍需更多版本样本。
4. `attr & 0x04` 的具体历史名称和脚本开启方式仍需与 PrimSetZ、V3DSet、V3D 相关 HCB 调用链进一步交叉验证。
5. 当前 reference 中未检索到足够的 V3D 直接脚本调用样例，因此全局坐标的具体视觉用途不应强行命名为“摄像机坐标”。
