# [`f_0005511C()`](Sakura_hcb_ir/Sakura/f_0005511C.lua:1) BGM 播放参数详细解析

> 本文根据原始 [`Sakura.hcb`](../../03_data/hcb_samples/Sakura.hcb)、IR [`Sakura.ir.json`](Sakura_hcb_ir/Sakura.ir.json) 和 [`f_0005511C.lua`](Sakura_hcb_ir/Sakura/f_0005511C.lua:1) 编写。由于旧 Lua-like 导出器存在参数整体右移，本文以原始负栈索引为准。

## 1. 函数定位

- 地址范围：`0x0005511C–0x00055201`；HCB 文件偏移：`348444–348673`；字节长度：`230`。
- 函数序言：`init_stack args=5, locals=2`。
- 直接 syscall：`IntToText`、`AudioStop`、`AudioType`、`AudioLoad`、`AudioVol`、`AudioPlay`。
- 直接调用函数：[`f_00055202()`](Sakura_hcb_ir/Sakura/f_00055202.lua:1)。

## 2. 五个真实入参

| 参数 | 真实作用 | 默认/特殊值 | 置信度 |
|---|---|---|---|
| `a0` | BGM 编号。经 `IntToText(a0, 3)` 格式化后拼接到 `BGM/` 或 `BGM2/`。 | 无本函数默认值；若为空，`IntToText`/路径行为需另验。 | 高 |
| `a1` | 切换收尾控制值，传给 [`f_00055202()`](Sakura_hcb_ir/Sakura/f_00055202.lua:1)，用于停止另一 Audio 槽。 | `-1`：跳过 `f_00055202`；`nil`：下游默认停止时长 `4500`；其他值：下游加 `1000` 后停止。 | 高 |
| `a2` | 循环播放开关。`a2 == 1` 或 `a2 == nil` 时调用 `AudioPlay(slot, true)`，否则调用 `AudioPlay(slot, nil)`。 | `nil/1` 循环；其他值不循环。 | 高 |
| `a3` | 目标音量，传给 `AudioVol(slot, a3, nil)`。 | `nil`：默认 `100`；`<=0`：归一化为 `0`。 | 高 |
| `a4` | 音频路径族选择。 | `a4 == 2` 使用 `BGM/`；其他值使用 `BGM2/`。注意这与直觉上的“2 号 BGM”无关。 | 高 |

## 3. 核心播放流程

```lua
function f_0005511C(a0, a1, a2, a3, a4)
    if a3 == nil then a3 = 100 end
    if G[215] == a0 then return end
    G[215] = a0

    if a4 ~= 2 then path = "BGM/" else path = "BGM2/" end
    path = path .. IntToText(a0, 3)

    if G[213] == 0 then G[213]=1; G[214]=0
    else G[213]=0; G[214]=1 end

    AudioStop(G[213], 100)
    AudioType(G[213], 1)
    AudioLoad(G[213], path)
    if a3 <= 0 then a3 = 0 end
    AudioVol(G[213], a3, nil)
    if a2 == 1 or a2 == nil then AudioPlay(G[213], true)
    else AudioPlay(G[213], nil) end

    if a1 ~= -1 then
        if a1 == nil then a1 = 1000 end
        f_00055202(a1)
    end
end
```

## 4. 参数到 Audio syscall 的对应关系

| syscall | 参数来源 | 具体含义 |
|---|---|---|
| `IntToText` | `a0`, 固定宽度 `3` | 把 BGM 编号格式化成三位字符串。 |
| `AudioStop` | `G[213]`, 固定 `100` | 先停止当前目标槽的旧播放，100 为停止淡出时长。 |
| `AudioType` | `G[213]`, 固定 `1` | 将当前槽绑定到 Audio 类型槽 `1`。 |
| `AudioLoad` | `G[213]`, 拼接路径 | 装载 `BGM/NNN` 或 `BGM2/NNN`。 |
| `AudioVol` | `G[213]`, `a3`, `nil` | 设置目标音量，脚本层通常为 `0..100`。 |
| `AudioPlay` | `G[213]`, `a2==1 or nil` | 真值时循环播放，否则非循环播放。 |
| `f_00055202` -> `AudioStop` | `G[214]`, `a1` 派生值 | 停止另一 Audio 槽，形成双槽切换/收尾。 |

## 5. 路径选择：BGM/ 与 BGM2/

关键判断是下游导出代码中的 `a5 == 2`，按真实槽位应理解为 `a4 == 2`：

- `a4 != 2`：路径前缀 `BGM/`；
- `a4 == 2`：路径前缀 `BGM2/`。

例如真实调用：

```lua
f_0005511C(44, nil, nil, 85, nil)
-- AudioLoad(slot, "BGM/044")
-- AudioVol(slot, 85, nil)
-- AudioPlay(slot, true)
```

若第四参数为 `2`：

```lua
f_0005511C(44, nil, nil, 85, 2)
-- AudioLoad(slot, "BGM2/044")
```

## 6. G[213]/G[214] 双槽切换

- `G[213]`：当前新 BGM 要装载和播放的槽；
- `G[214]`：本次切换中要收尾停止的另一槽；
- 每次检测到 BGM 编号变化时，两个槽在 `0/1` 之间交替。

BGM 编号没有变化时：

```lua
if G[215] == a0 then return end
```

所以重复调用同一个 BGM 编号不会重复执行 `AudioLoad`/`AudioPlay`。

## 7. f_00055202() 收尾停止

下游函数 [`f_00055202()`](Sakura_hcb_ir/Sakura/f_00055202.lua:1) 的实际逻辑是：

- 参数为 `nil`：设置 `4500`，然后 `AudioStop(G[214], 4500)`；
- 参数非 `nil`：先加 `1000`，然后 `AudioStop(G[214], 参数+1000)`；
- `G[214]` 是切换前保留的另一音频槽。

因此 `a1` 不是新 BGM 播放时长，而是**旧 BGM 槽的切换后停止控制值**。

## 8. f_00036848() 的实际效果

[`f_00036848()`](Sakura_hcb_ir/Sakura/f_00036848.lua:1) 调用：

```lua
f_0005511C(44, nil, nil, a0, nil)
```

按真实参数位置，这意味着：

- 固定 BGM 编号为 `44`，即 `BGM/044`；
- `a1=nil`：旧槽按 `f_00055202` 默认时长收尾；
- `a2=nil`：循环播放；
- `a3=a0`：`f_00036848` 的唯一参数实际是目标音量；
- `a4=nil`：使用 `BGM/` 而不是 `BGM2/`。

所以此前把 `f_00036848(a0)` 的唯一参数理解成“BGM 编号”并不准确。更准确是：

> `f_00036848(volume)`：以标准模式循环播放固定的 `BGM/044`，并把传入值作为目标音量。

例如开场：

```lua
f_00036848(nil)
```

下游 `f_0005511C()` 会把音量默认成 `100`，因此相当于以 100% 音量循环播放 `BGM/044`。

## 9. 典型参数示例

| 调用 | 结果 |
|---|---|
| `f_0005511C(44, nil, nil, nil, nil)` | 播放 `BGM/044`，音量默认 100%，循环，旧槽默认约 4500 ms 后停止。 |
| `f_0005511C(44, nil, nil, 50, nil)` | 播放 `BGM/044`，目标音量 50%，循环。 |
| `f_0005511C(44, 2000, nil, 100, nil)` | 播放 `BGM/044`，循环，另一槽约 `3000 ms` 后停止。 |
| `f_0005511C(44, -1, nil, 100, nil)` | 播放 `BGM/044`，不调用 `f_00055202`，不额外停止另一槽。 |
| `f_0005511C(44, nil, 0, 100, 2)` | 播放 `BGM2/044`，非循环，目标音量 100%。 |

## 10. 最终结论

### 高置信度

- `a0` 控制三位 BGM 编号，决定 `.../NNN`；
- `a1` 播放时是旧槽收尾停止时长控制，传给 `f_00055202`，而非新 BGM 的播放时长；
- `a2` 控制是否循环：`nil/1` 循环，其他值非循环；
- `a3` 是目标音量，缺省 `100`，单位为百分比；
- `a4 == 2` 选择 `BGM2/`，其他值选择 `BGM/`；
- `G[213]/G[214]` 实现两个 Audio 槽交替切换；
- `G[215]` 记录当前 BGM 编号，重复编号会直接返回。

### 当前需要修正的旧结论

- `f_00036848()` 的唯一参数不是 BGM 编号，而是传入 `f_0005511C` 第四位置的目标音量；
- 固定值 `44` 才是该包装器选择的 BGM 编号；
- `BGM/` 与 `BGM2/` 由 `f_0005511C` 的第五真实参数 `a4` 控制；
- BGM 切换的旧槽停止时长由真实第二参数 `a1` 经 `f_00055202` 转换后决定。
