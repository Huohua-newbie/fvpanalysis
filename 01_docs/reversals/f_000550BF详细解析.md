# [`f_000550BF()`](Sakura_hcb_ir/Sakura/f_000550BF.lua:1) 逐条反汇编与作用解析

## 1. 核心结论

[`f_000550BF()`](Sakura_hcb_ir/Sakura/f_000550BF.lua:1) 是一个**四路环境音/环境声统一刷新函数**。

它的主要工作是：

1. 取得一个统一的环境声参数；
2. 将该参数分别传给环境声通道 `0`、`1`、`2`、`3`；
3. 每一路都调用 [`f_00054EB1()`](Sakura_hcb_ir/Sakura/f_00054EB1.lua:1)；
4. 最后设置全局标志 `G[273] = true`。

等价伪代码为：

```lua
function f_000550BF(value)
    if value == nil then
        value = 2000
    end

    f_00054EB1(nil, 0, value, 0, nil)
    f_00054EB1(nil, 1, value, 0, nil)
    f_00054EB1(nil, 2, value, 0, nil)
    f_00054EB1(nil, 3, value, 0, nil)

    G[273] = true
end
```

其中 `value` 在 [`f_000550BF()`](Sakura_hcb_ir/Sakura/f_000550BF.lua:1) 内部被直接传给 [`f_00054EB1()`](Sakura_hcb_ir/Sakura/f_00054EB1.lua:1) 的第三个真实参数；结合下游函数的语义，它更接近**环境音音量/统一环境声参数**，而不是等待时长。

对于当前 Sakura 剧情中的常见调用：

```lua
f_000550BF(nil)
```

其实际默认值为 `2000`。

- 函数地址：`0x000550BF`。
- IR 起始地址：`348351`，见 [`Sakura.ir.json`](Sakura_hcb_ir/Sakura.ir.json:8979028)。
- 函数签名：`init_stack args=1, locals=0`。
- 主体范围：`0x000550BF–0x00055109`。
- 直接调用的函数：[`f_00054EB1()`](Sakura_hcb_ir/Sakura/f_00054EB1.lua:1)，共 4 次。
- 直接写入的全局槽：`G[273]`。
- CFG 为线性流程，只有入口的 `nil` 默认值分支，见 [`Sakura.cfg.json`](../../03_data/cfg/Sakura.cfg.json:354053)。

## 3. 参数槽位

导出函数头为：

```lua
function f_000550BF(a0)
```

但函数体读取的是导出中的 `a1`，这是当前 Lua-like 导出器的参数槽编号偏移现象。根据 `init_stack args=1`、`push_stack -2`，唯一真实参数应记为 `P1`：

| 真实参数 | 原始栈槽 | 导出名称 | 作用 |
|---|---:|---|---|
| `P1` | `-2` | 导出中的 `a1` | 四路环境声统一传入参数；`nil` 时默认 `2000` |

推荐将其命名为：

```text
environment_audio_value
```

当前仅凭本函数和下游数据流，不能把它绝对命名为“音量”或“持续时间”；但可以确定它被四路环境音处理函数统一使用，并最终进入 [`SoundVol()`](../syscalls/24_Sound.md:1) 的音量参数位置。

### 4.6 设置完成标志

| 地址 | 原始字节 | 指令 | 解析 |
|---|---|---|---|
| `0x00055104` | `09` | `push_true` | 压入 `true`。 |
| `0x00055105` | `15 11 01` | `pop_global 273` | 设置 `G[273] = true`。 |
| `0x00055108` | `04` | `ret` | 返回。 |
| `0x00055109` | `04` | `ret` | 相邻冗余返回。 |

`G[273]` 会被 [`f_00054EB1()`](Sakura_hcb_ir/Sakura/f_00054EB1.lua:67-73) 读取：当它为 `true` 时，某些环境声更新路径会直接跳转到收尾位置。因此它不是普通的“函数执行完成标志”，更可能是：

> **环境声系统已被统一初始化/刷新，后续重复调用可以避免不必要的重新加载。**

不过，`G[273]` 的完整生命周期还受 [`f_0005510A()`](Sakura_hcb_ir/Sakura/f_0005510A.lua:1) 和 [`f_00055113()`](Sakura_hcb_ir/Sakura/f_00055113.lua:1) 等函数控制，因此它也可能表示当前环境声缓存已经有效。

## 5. 下游 [`f_00054EB1()`](Sakura_hcb_ir/Sakura/f_00054EB1.lua:1) 的参数映射

为了确认 [`f_000550BF()`](Sakura_hcb_ir/Sakura/f_000550BF.lua:1) 的唯一参数，需要把四次调用放入 [`f_00054EB1()`](Sakura_hcb_ir/Sakura/f_00054EB1.lua:1) 的真实参数槽中分析。

建议将 [`f_00054EB1()`](Sakura_hcb_ir/Sakura/f_00054EB1.lua:1) 的五个真实参数命名为：

```lua
f_00054EB1(resource_name, channel, value, mode, volume)
```

在 [`f_000550BF()`](Sakura_hcb_ir/Sakura/f_000550BF.lua:13-36) 中传入：

```lua
resource_name = nil
channel       = 0..3
value         = P1
mode          = 0
volume        = nil
```

### 5.1 第一个真实参数：资源名

当第一个参数非 `nil` 时，下游会执行：

```lua
path = "se_env/" .. IntToText(channel, 3)
```

之后把路径传给 `SoundLoad`。

而 [`f_000550BF()`](Sakura_hcb_ir/Sakura/f_000550BF.lua:1) 固定传入 `nil`，因此它不是在这里指定一个新的环境音资源文件名。

### 5.2 第二个真实参数：环境声通道编号

下游将通道编号加 `20`：

```lua
channel_state = channel + 20
```

于是四次调用形成：

| `f_000550BF()` 传入值 | 下游状态编号 |
|---:|---:|
| `0` | `20` |
| `1` | `21` |
| `2` | `22` |
| `3` | `23` |

这些状态编号对应四个全局缓存槽：

| 状态编号 | 全局缓存 |
|---:|---|
| `20` | `G[269]` |
| `21` | `G[270]` |
| `22` | `G[271]` |
| `23` | `G[272]` |

因此，第二个参数确定当前操作的是哪一路环境声。

### 5.3 第三个真实参数：统一环境声数值

第一个函数参数 `P1` 被作为第三个真实参数传给 [`f_00054EB1()`](Sakura_hcb_ir/Sakura/f_00054EB1.lua:1)。下游代码对第三个参数先限制在 `0..3`，随后加 `20`，这部分主要用于内部环境声通道/状态索引处理；在 [`f_000550BF()`](Sakura_hcb_ir/Sakura/f_000550BF.lua:1) 的具体调用中，实际传入的 `P1` 是统一值，因此它代表一项四路共用的环境声控制量。

由于它还被保存/比较并参与下游音频调用，最保守的名称是：

> **统一环境声参数**。

在当前 `f_000550BF()` 路径中，不能仅凭局部代码把它绝对命名为“播放时长”。更可能是用于环境声状态或音量模板的数值。

### 5.4 第四真实参数：更新/播放模式

[`f_000550BF()`](Sakura_hcb_ir/Sakura/f_000550BF.lua:1) 固定传入 `0`。下游在该参数为 `0` 时走默认的环境声更新路径，而不是带有特殊资源/状态判定的路径。

可暂命名为：

> **环境声更新模式**。

### 5.5 第五真实参数：音量默认值

[`f_000550BF()`](Sakura_hcb_ir/Sakura/f_000550BF.lua:1) 固定传入 `nil`。下游将其默认化为 `100`，并传给：

```lua
SoundVol(channel, 100, nil)
```

所以在 [`f_000550BF()`](Sakura_hcb_ir/Sakura/f_000550BF.lua:1) 的常规路径中，四路环境声使用默认音量 `100`。

## 6. `f_000550BF()` 的真实业务作用

将本函数与下游 [`f_00054EB1()`](Sakura_hcb_ir/Sakura/f_00054EB1.lua:1) 合起来，可以还原出以下流程：

```text
统一准备环境声参数
→ 依次处理环境声通道 0
→ 依次处理环境声通道 1
→ 依次处理环境声通道 2
→ 依次处理环境声通道 3
→ 标记环境声状态已准备
```

它不是：

- 单路声音播放函数；
- BGM 播放函数；
- 普通 SE 播放函数；
- 声音淡入淡出函数；
- 图元或舞台函数；
- 线程等待函数。

它更像：

> **将当前场景的四路环境声状态统一刷新/初始化的公共函数。**

## 7. 与 [`f_000172A9()`](Sakura_hcb_ir/Sakura/f_000172A9.lua:1) 的关系

[`f_000172A9()`](Sakura_hcb_ir/Sakura/f_000172A9.lua:1) 的主体正是连续调用四次环境声处理函数：

```lua
f_00054EB1(nil, 0, 2000, 0, nil)
f_00054EB1(nil, 1, 2000, 0, nil)
f_00054EB1(nil, 2, 2000, 0, nil)
f_00054EB1(nil, 3, 2000, 0, nil)
```

而 [`f_000550BF()`](Sakura_hcb_ir/Sakura/f_000550BF.lua:1) 的结构是：

```lua
f_00054EB1(nil, 0, P1, 0, nil)
f_00054EB1(nil, 1, P1, 0, nil)
f_00054EB1(nil, 2, P1, 0, nil)
f_00054EB1(nil, 3, P1, 0, nil)
G[273] = true
```

所以两者关系可以明确为：

| 函数 | 第三个真实参数 | 额外行为 |
|---|---:|---|
| [`f_000172A9()`](Sakura_hcb_ir/Sakura/f_000172A9.lua:1) | 固定 `2000` | 只负责四路刷新，并受 `G[274]` 控制 |
| [`f_000550BF()`](Sakura_hcb_ir/Sakura/f_000550BF.lua:1) | 外部参数，nil 默认 `2000` | 四路刷新后设置 `G[273]=true` |

因此 [`f_000550BF()`](Sakura_hcb_ir/Sakura/f_000550BF.lua:1) 可以视为 [`f_000172A9()`](Sakura_hcb_ir/Sakura/f_000172A9.lua:1) 的**参数化版本/完成标志版本**。

## 9. 最终伪代码

```lua
function f_000550BF(P1)
    if P1 == nil then
        P1 = 2000
    end

    for channel = 0, 3 do
        -- resource_name=nil
        -- channel=0..3
        -- value=P1
        -- mode=0
        -- volume=nil -> 下游默认 100
        f_00054EB1(nil, channel, P1, 0, nil)
    end

    G[273] = true
end
```

## 10. 最终结论

1. [`f_000550BF()`](Sakura_hcb_ir/Sakura/f_000550BF.lua:1) 只有一个真实入参；`nil` 时默认 `2000`。
2. 它固定调用 [`f_00054EB1()`](Sakura_hcb_ir/Sakura/f_00054EB1.lua:1) 四次，通道参数依次为 `0/1/2/3`。
3. 第一个传给 [`f_00054EB1()`](Sakura_hcb_ir/Sakura/f_00054EB1.lua:1) 的参数固定为 `nil`，因此当前函数不指定新的声音资源文件。
4. 第四参数固定为 `0`，选择默认环境声更新路径。
5. 第五参数固定为 `nil`，下游默认音量为 `100`。
6. 唯一入参 `P1` 是四路共用的环境声控制数值；在现有调用中通常使用默认值 `2000`。
7. 函数末尾设置 `G[273]=true`，表示环境声状态已经完成一轮统一处理/进入有效状态。
8. [`f_000550BF()`](Sakura_hcb_ir/Sakura/f_000550BF.lua:1) 与 [`f_000172A9()`](Sakura_hcb_ir/Sakura/f_000172A9.lua:1) 具有相同的四路处理骨架；前者是参数化版本，并额外设置完成标志。

最准确的功能标签是：

> **四路环境声状态统一刷新/初始化函数**。
