# [`f_0005207E()`](Sakura_hcb_ir/Sakura/f_0005207E.lua:1) 主舞台作用对象的实机验证补充

## 1. 实验条件

针对 [`f_0005207E()`](Sakura_hcb_ir/Sakura/f_0005207E.lua:1) 对应的 `$vm` 运镜调用，保持横纵坐标参数和运动时长不变，并将第三个运动参数 `P3` 手动改为 `nil`。

原始样本中的典型参数为：

```lua
f_0005207E(-255, 70, 1600, nil, 1600, nil, nil, nil, nil, nil, nil, nil)
```

其中：

- `P1 = -255`：目标 X；
- `P2 = 70`：目标 Y；
- `P3 = 1600`：原本用于 Z/纵深方向的运动参数；本次改为 `nil`，以排除缩放或远近变化对判断的干扰；
- `P5 = 1600`：主运动时长。

## 2. 实机现象

实验观察到：

> 即使将第三参数 `P3` 改为 `nil`，画面本身仍然整体向左下角移动。

这说明观察到的主要现象来自 `P1/P2` 对二维位置的控制，而不是 `P3` 引起的 Z 轴运动、缩放或透视变化。

## 3. 对摄像机/主舞台假设的判定

在约定坐标系中：

- 左上角为 `(0,0)`；
- X 正方向向右；
- Y 正方向向下；
- `P1=-255` 表示目标位置向横轴负方向，即向左；
- `P2=70` 表示目标位置向纵轴正方向，即向下。

若运动的是摄像机，摄像机向左下移动时，固定世界内容相对于摄像机应表现为向右上移动。

若运动的是承载画面的主舞台图元，主舞台内容本身应表现为向左下移动。

实际观察为画面整体向左下移动，因此支持第二种解释：

> [`f_0005207E()`](Sakura_hcb_ir/Sakura/f_0005207E.lua:1) 通过其核心函数 [`f_000519FC()`](Sakura_hcb_ir/Sakura/f_000519FC.lua:1) 运动的是主舞台/主演出图元，而不是独立的摄像机位置。

## 4. 与静态反汇编的结合

该实机结论与静态代码证据一致：

1. [`f_0005207E()`](Sakura_hcb_ir/Sakura/f_0005207E.lua:1) 只是把参数转发给 [`f_000519FC()`](Sakura_hcb_ir/Sakura/f_000519FC.lua:1)；
2. 核心函数最终把运动发给具体的 `prim 190/191`；
3. 二维位置通过 [`MotionMove()`](../syscalls/18_Motion.md:214) 处理；
4. Z 方向通过 [`MotionMoveZ()`](Sakura_hcb_ir/Sakura/f_0005243F.lua:43-49) 处理；
5. 旋转通过 [`MotionMoveR()`](Sakura_hcb_ir/Sakura/f_0005253B.lua:43-49) 处理；
6. 代码中没有独立摄像机对象、摄像机矩阵或专用 Camera Motion 接口。

因此，`P3=nil` 后仍保持左下平移，进一步隔离并确认了 `P1/P2 -> 主舞台 prim 的二维平移` 这一关系。

## 5. 结论的精确表述

此前“可能是主舞台，也可能是摄像机”的静态层面判断，现在可以根据实机结果收紧为：

> 在 Sakura 当前这条 `$vm` 调用路径中，实际被运动的是主舞台本身，或者更严格地说，是承载主舞台/主演出画面的 prim 190/191 及其相关 prim 组。

“主舞台本身”应理解为引擎中的舞台图元或舞台图元组，而不是全局摄像机。由于主舞台可能是父 prim，画面中的背景、CG、立绘和特效是否全部同步移动，还取决于它们的父子层级关系。

## 6. 对参数语义的补充

用户给出的 KS 宏：

```ks
[macro name="$vm" #x="-255" #y="70" #z="1600" #speed="1600"]
```

现在可以更准确地描述为：

```text
在 speed=1600 ms 的时间内，将主舞台/主演出图元移动到目标平面位置 x=-255、y=70；z=1600 时还附带纵深方向运动，可能产生缩放或远近效果。
```

当 `z` 改为 `nil` 时：

- Z/纵深分量被去除或不再提供有效目标值；
- 但 X/Y 平移仍然发生；
- 画面仍向左下移动，直接证明其二维舞台运动方向。

## 7. 最终结论

实机验证确认：

- 该函数族不是在移动独立摄像机；
- 它直接驱动主舞台/主演出 prim；
- `P1=-255`、`P2=70` 对应主舞台向左下方向的二维位置变化；
- `P3` 主要负责额外的 Z/纵深分量，置为 `nil` 后不会改变上述左下平移结论；
- `P5=1600` 是这轮主舞台运动的持续时间，单位约为毫秒。

因此，后续在文档中应将 [`f_0005207E()`](Sakura_hcb_ir/Sakura/f_0005207E.lua:1) 的整体作用描述为：

> **主舞台/主演出图元的复合运镜函数**，而不是摄像机位置运动函数。
